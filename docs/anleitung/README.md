# Einrichtungsanleitung für Dritte

Vierseitige A4-Anleitung (Stand: App-Version 0.1.36) zum Aufbauen und Einrichten der Sonnhalde Fotobox.

- `Sonnhalde-Fotobox-Einrichtungsanleitung.pdf` – zum Drucken und Weitergeben
- `index.html` – gleicher Inhalt als eigenständige Webseite (Logo und Screenshots eingebettet, ca. 9 MB); im Browser mit «Drucken» als PDF speichern

Das PDF stammt aus Claude Design (A4, vier Seiten, mit Screenshots). Nach Änderungen an `index.html` das PDF neu erzeugen (Chromium, A4, Hintergrund drucken).
Die Anleitung beruht auf Tests mit einem Xiaomi-Tablet und dem DNP QW410 mit WCMPlus; nicht Getestetes ist als solches gekennzeichnet.
